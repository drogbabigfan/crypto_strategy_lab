## 2. TBM 스케일링 문제 발견

### 2.1 기존 문제

```python
# 기존 TBM 설정
sl_mult = 2.0
pt_mult = 2.5
vertical_bars = 100
```

`realized_vol`은 **1-bar 변동성** (24-bar rolling std of returns):
- median σ = 0.24% (1-bar 기준)
- PT barrier = 2.5 × 0.24% = **0.60%**
- SL barrier = 2.0 × 0.24% = **0.48%**

**문제:** 100바 동안 ±0.5% 범위 안에 있을 리 없음 → **Neutral 0.1%**

### 2.2 해결: sqrt(T) 스케일링

시간 스케일링 공식:
```
σ_T = σ_1 × sqrt(T)
```

코드 수정 (`research/label_optimizer/tbm.py`):
```python
# Calculate barriers with time-scaling
# σ_T = σ_1 * sqrt(T) for holding period T bars
scaled_sigma = sigma * math.sqrt(self.config.vertical_bars)
pt_level = entry_price * (1 + self.config.pt_mult * scaled_sigma)
sl_level = entry_price * (1 - self.config.sl_mult * scaled_sigma)
```

## 5. 핵심 인사이트

### 5.1 mult와 T의 관계

sqrt(T) 스케일링이 적용되면:
- `mult`는 "T-bar 변동성의 몇 σ에 barrier를 놓을 것인가"
- T가 바뀌어도 같은 mult면 같은 "시그마 배수"

```
mult=1.0, T=10  → Neutral 25%
mult=1.0, T=20  → Neutral 26%
mult=1.0, T=50  → Neutral 28%
```

**mult 고정하고 T만 조정해도 Neutral 비율 유지됨.**

### 5.2 mult 선택 기준

| mult | 의미 | Neutral |
|------|------|---------|
| 1.0σ | 표준 범위 | ~34% |
| 1.5σ | 보수적 | ~58% |
| 2.0σ | 매우 보수적 | ~80% |

**1.0σ가 가장 균형 잡힌 설정.**
